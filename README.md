# 🛡️ Zucks-Anti-Cheat

A modern, multi-layered anti-cheat and server protection framework.

## Features

- **Layer 4/7 DDoS Protection** — SYN flood, rate limiting, connection caps
- **Stateful DPI** — Packet structure validation, fragment reassembly guard
- **Anti-Cheat Engine** — Behavioral analysis, signature scanning, integrity checks
- **Web Dashboard** — Real-time monitoring & control panel
- **REST API** — Programmatic access for integration
- **SQLite Logging** — Persistent ban/log storage
- **Webhook Alerts** — Discord/Telegram notifications
- **Hot-Reload Config** — Update rules without restart
- **Docker Support** — One-command deployment
